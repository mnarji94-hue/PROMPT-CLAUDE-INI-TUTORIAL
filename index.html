Peringatan Wajib Dibaca!

Sekarang tinggal pencet Next, tapi baca dulu 4 aturan penting di bawah ini supaya tidak gagal saat eksekusi:

1

Siapkan Materi Dasar: Minta Claude membuatkan naskah, deskripsi adegan, dan konsep terlebih dahulu, lalu salin dan pasang pada kolom yang tersedia di prompt nanti.

2

Jangan Langsung Kirim Prompt! Buat Voice Over (VO) dulu di ElevenLabs (via website atau aplikasi). Tempel naskah tadi, pilih karakter suara favoritmu, tunggu proses selesai, lalu download file MP3-nya.

3

Lampirkan Audio ke Claude: Sertakan file voice over tadi ke dalam chat Claude dengan cara tekan tombol tanda (+) → pilih File → unggah file MP3 ElevenLabs milikmu.

4

Trik Jika Claude Menolak: Jika Claude merespons bahwa Remotion tidak tersedia atau kendala serupa, cukup balas dengan mengetik satu kata: "bikin".
